# New School Website System

A Serverless school website platform for Anuban Chumsang (Wat Thap Krith Klang).\n\nSee the setup guide below for Supabase, GitHub Pages, Google Drive, Apps Script, and Telegram configuration.\n\n## Project\n\n- Frontend: HTML5, Tailwind CSS CDN, JavaScript ES Modules style\n- Database/Auth: Supabase PostgreSQL + RLS\n- File delivery: Google Drive (no Supabase Storage)\n- Notifications: Google Apps Script + Telegram Bot API\n- Hosting: GitHub Pages\n\n## Repository contents\n\n- `index.html`: public homepage with latest news\n- `personnel.html`: personnel directory and personal website links\n- `admin/login.html`, `admin/dashboard.html`: protected CMS starter\n- `assets/js`: Supabase client and API helpers\n- `gas/Code.gs`: Google Drive listing and Telegram notification endpoint\n- `supabase/schema.sql`: schema/security reference\n\n## Deploy and configure\n\n1. Review Supabase tables and RLS policies in project `uwebbofczidcfnjbvsqu`.\n2. Add the first owner row to `public.admin_users` using the UUID of an existing trusted Auth account.\n3. Set up the Google Apps Script Script Properties `DRIVE_FOLDER_ID`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.\n4. Set the Apps Script Web App URL in `assets/js/api.js` as `window.SCHOOL_GAS_WEB_APP_URL`.\n5. Enable GitHub Pages from `main` / root and set Supabase Auth Site URL/redirect URLs.\n\nSee the source files and Supabase migration history for the full RLS implementation.\n
